# Santosh

Computer vision engineer focused on real-time detection and tracking in industrial settings.

I build camera-based systems that detect, track, and count moving objects on the floor — so teams get reliable counts and evidence without staring at footage all day.

---

## What I do

| Capability | Outcome |
|------------|---------|
| Detection & tracking | Live pipelines that lock onto objects across frames and count them once |
| Multi-camera inference | More streams per GPU by matching frame rate to the process, not to playback |
| Operational evidence | Timestamped events and imagery that stand up as an audit trail |

---

## Approach

- Prove the hard part on saved frames before blaming a live stream
- Treat lighting, mount, and occlusion as first-class failure modes — not automatic model bugs
- Validate cheaply before buying hardware
- Keep active development on local disk, not cloud-synced folders

---

## Stack

Python · YOLOv8 · OpenCV · multi-object tracking · PyTorch · TensorFlow · labeling & dataset tooling · industrial IP cameras / NVR
